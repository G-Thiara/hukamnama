## [1.6.0] — 2026-08-06
### Changed
- Switched synthesis generation from Claude Haiku to Claude Sonnet for significantly better quality
- `api/warm.js` now clears today's Redis cache before regenerating, ensuring Sonnet is used on manual refresh

---

## [1.5.0] — 2026-07-30
### Added
- AI disclaimer footer: "Essence generated by AI · Not a scholarly interpretation"
- `PROJECT_STORY.md` — full narrative of how the project was built, for interview prep

---

## [1.4.0] — 2026-07-28
### Fixed
- **Critical**: switched GurbaniNow fetch to `/today` endpoint instead of date-specific URL. GurbaniNow's `/today` uses their own IST clock, avoiding the issue where the date-specific URL returned empty results before Amrit Vela (~3-5am IST)
- Added `api/debug.js` endpoint to inspect what GurbaniNow returns from within Vercel's environment

### Added
- Retry with exponential backoff on frontend (3 attempts, 1s/2s delays) before falling back to verses-only

---

## [1.3.0] — 2026-07-27
### Added
- Upstash Redis persistent caching — synthesis and hukamnama cached by IST date key (`hukamnama:YYYY-MM-DD`)
- `hukamnama:latest` fallback key — serves yesterday's data if today's fetch fails
- Stale notice shown above essence card when serving fallback data
- Vercel cron job at 9am IST (3:30am UTC) to pre-warm cache daily via `api/warm.js`

### Fixed
- Serverless in-memory cache was resetting on every cold start, causing Claude to be called on every request

---

## [1.2.0] — 2026-07-26
### Fixed
- **Critical timezone bug**: Vercel servers are in the US; GurbaniNow was returning different days' data depending on server location. Fixed by computing IST explicitly using UTC+5:30 offset arithmetic
- Two-call race condition: browser was fetching GurbaniNow directly AND calling `/api/synthesis` separately — could get mismatched days. Fixed by having `/api/synthesis` return both hukamnama + synthesis in one response

### Added
- Vercel Analytics (`/_vercel/insights/script.js`)
- `api/warm.js` endpoint for manual cache refresh

---

## [1.1.0] — 2026-07-25
### Added
- Domain gurudahukam.com connected (Namecheap → Vercel nameservers)
- GitHub → Vercel auto-deploy pipeline
- `api/synthesis.js` Vercel serverless function (replaces local Express server)
- Claude Haiku synthesis with generate→review loop (up to 3 attempts)
- In-memory daily caching in serverless function

### Changed
- Header: English line made prominent (navy, larger), Punjabi line secondary and muted
- English line moved above Punjabi line in header
- Verse layout: English first, then Gurmukhi, then transliteration (option-b layout)

### Fixed
- `||1||`, `||Pause||`, trailing numbers stripped from English translations
- Markdown headings/bold stripped from Claude responses
